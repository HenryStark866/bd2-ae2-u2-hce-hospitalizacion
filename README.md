# AE2-U2 · Construyendo una base de datos NoSQL (MongoDB)
HCE básica de Antioquia, subsistema de hospitalización. Modelo documental híbrido. Datos 100 % ficticios.

Reproducir (MongoDB 8.x + mongosh):
    mongosh --file scripts/01_crear_esquema.js
    mongosh --file scripts/02_carga_datos.js
    mongosh --file scripts/03_consultas.js

Contenido: scripts/, datos_json/, resultados/, capturas/, ia_evidencia/, informe_fuente/.
Informe: Grupo1_AE2_U2.pdf (trabajo individual; se regenera con `python informe_fuente/generar_informe.py`).
